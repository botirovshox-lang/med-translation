# ТЗ: фото без грубого брака с первой выгрузки + петля «ИИ правит — ИИ пишет правила»

Утверждено 24.10.2026 после четырёх критиков (архитектор, тимлид, бизнес-процесс, клиент).
Решения владельца — `BACKLOG.md`, «Петля „ИИ правит — ИИ пишет правила“».

## Что ломается сейчас (корпус 2, боевой прогон 23.10.2026)
| Файл | Брак глазами клиента | Причина |
|---|---|---|
| 65 разворот | переводы двух блоков друг на друге; русские хвосты у корешка; верх страницы не переведён; строки кеглем ~4 px | наложение печати не проверяется; рамки строк короче изогнутой строки; детектор пропустил ~26% строк; пол кегля у печати по маске — 0.6 от порога |
| 66 визитка | e-mail стёрт, перепечатан и лёг на телефон | блок «перевод = оригинал» перепечатывается |
| 68 табличка KK→RU | казахские строки «переведены» как есть | один блок слил строки двух языков |

## Законы, общие для всех шагов
1. **Хуже, чем оригинал в своём месте, не отдаём.** Порядок предпочтений клиента: перевод
   на месте → плашка в своей рамке → оригинал нетронутым → подпись под фото. Наложение
   текста на текст, пятно стирания без текста и нечитаемо мелкий шрифт — брак.
2. **Оставленное оригиналом называется числом** в отчёте выгрузки (без терминов на экране).
3. **Платных прогонов ради проверки нет** (инв. 7): эталон — замороженные чтение и перевод.
4. **Каждое правило** — код + тест + запись в `docs/rules/pdf-reading.md` (раздел Ю).
5. Клиент не видит денег, моделей, «кругов», «ИИ» (инв. 22а/24а).

## Шаги

### Заход 1 (сегодня)
**Б1. Эталонный набор фото и мерки «до»** — `tools/photo_bench.py`.
- 21 фото корпуса (19–30, 61–70) из детерминированных рецептов `tools/corpus_build.py --set2`.
- Замороженные ответы чтения и перевода: `tests/fixtures/photo_bench/<id>/read.json`, `tr.json`
  (прочитаны один раз агентами по вырезкам настоящего конвейера, без поставщика).
- Прогон: настоящий конвейер `corpus_claude_images` (проход 3) → выгрузка → пиксельная приёмка
  (`export_qa`) → `summary.json`: находки по видам, число «оставлено оригиналом», подписей.
- База «до» снимается на SHA до любых правок (`tests/fixtures/photo_bench_baseline.json`);
  `--check` падает, если у файла выросла сумма весов находок сверх допуска 1.
- DoD: прогон без сети и без модели; база записана; отчёт сравнения печатается таблицей.

**Ю1. «Перевод = оригинал» — не трогаем** (66). В `_export_images` до сборки `items`,
рядом с `ov_["leave"]`: блок, чей перевод совпадает с оригиналом (NFKC, регистр, пробелы),
не стирается и не печатается; счётчик `img_same`. Приёмке он не «непереведённый».
Тест — синтетика в `tests/test_image_text.py`/`test_image_scan.py`.

**Ю2. Пол кегля у печати по маске** (65г). Печать мельче `IMG_FONT_MIN_PX` (по высоте
картинки) уходит на плашку в своей рамке; плашка тоже мельче — блок остаётся оригиналом
нетронутым (не подписью), счётчик `img_small_kept`. Замер бенчем: волна подписей недопустима.

**Ю3. Сторож наложений** (65а, 66). В проходе 3 `render_target`, после раскладки и до
заливки: прямоугольник печати блока (с учётом угла/дуги) не пересекает рамку чужого
блока и печать соседа (части одного `blkItem` и соседи `leave`/`skip` — исключения);
пересёкся — «теснее» без роста, потом плашка в своей рамке, потом оригинал нетронутым.
В отчёт — `collide`, в счёт петли — тяжёлый.

**Д1. Деньги проверки — доля выручки.** Потолок предпечатной проверки на файл =
min(`PREPRESS_MAX_USD`, `PREPRESS_REV_SHARE` (0.3) × страницы файла × цена страницы
продажи), не ниже `PREPRESS_MIN_USD` (0.10). Расход — шаг `prepress` в `price_rules`
(`ONLY_ALL`: затрата наша, лимит клиента его не режет), событие `waste.prepressCap`.

**Д2. Ожидание «Готовим файл» ограничено.** Ждали дольше `PREPRESS_WAIT_S` (180 с) —
выгрузка собирается без проверки с честной пометкой, проверка догоняет в фоне и
следующая выгрузка берёт проверенный файл.

**Выкат 1:** все `tests/test_*.py`, node-тесты затронутых экранов, бенч «после» не хуже базы.
Правка `image_text.py` меняет отпечаток кода проверки — у проверенных файлов проверка
пройдёт заново при следующей выгрузке (под потолком Д1). Коммит, пуш, `git pull`,
рестарт `medcat medcat-worker`.

### Заход 2
- **Ю4. Блок двух языков делится на разборе**, до перевода: строки с отличительными
  буквами языка оригинала — переводятся, строки без них, целиком из букв языка перевода, —
  оригиналом. Данные — `lang_rules.json` (`distinctive`); нет записи — молчим.
- **Устойчивые id блоков** (`part|i` + хеш рамки) вместо индекса `x<n>` у правок (tune.json),
  с переносом старых: без этого деление блоков и новые места сажают правки на чужие места.
- **Л1. Оферта и политика:** п. 6.2.3 о вырезках (30 суток, удаление с проектом, передача
  поставщику на условиях разд. 5, не для обучения моделей, в бэкапах — в сроке 6.1), в 5.1 —
  «фрагменты изображений», в 6.3 — вырезки охвачены обращением; `legal.VERSION`; чистка по сроку.
  Включается ДО первого сохранения вырезок.

### Заход 3 — правки с параметрами (этапы 2–3)
Каталог правок места: стереть / напечатать (масштаб, теснее) / плашка (поле) / оригинал /
подпись / разделить. Код исполняет и бесплатно откатывает то, что пиксельно хуже; ИИ
выбирает из 2–4 пронумерованных вариантов номером, смотрит только изменённые места.
Новые действия — в `IMAGE_ACTIONS`, `_pp_img_ov`, `_GROUPS`.

### Заход 4 — случаи и правила (этап 4)
- Нерешённое место (после кругов осталась находка веса ≥2) → случай `prepressCases`
  файлами в `data/` (не в STATE, не в `/api/seed`), вырезки 30 дней, удаление с проектом.
- Агент в начале сессии разбирает случаи (как `export-review`): правило в код + тест →
  все тесты + фото-бенч + `corpus_offline` + эталоны 8/19/20/14 не хуже → выкат
  (решение владельца 3: не ждать второй организации).
- Журнал правил в админке (суперу): где сработало, «выключить»; правило-проба
  выключается само после 1 провала на живом файле, утверждённое — после 2.
- Правила-данные (`LearnedRules`) — «проба» с первого успеха, ночная пересборка бенча.

### Заход 5 — модель чинит разбор (этап 5)
`split_block` (модель называет блок, делит код), `add_region` (модель — грубое место,
рамку к буквам подтягивает код; нет букв — отказ; хвост строки у корешка дочитывается
этим путём, а не стирается), выпрямление страницы — отдельной работой.

## Метрики владельцу
Доля фото-файлов без находок веса ≥2 с первой выгрузки; доля мест, оставленных оригиналом;
медиана и p95 ожидания «Готовим файл»; $ проверки на файл и доля упёршихся в потолок.
