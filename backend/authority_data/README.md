# Справочники-источники приказов

Сюда кладутся отраслевые справочники. Совпадение пары «оригинал → перевод»
со справочником даёт записи глоссария уровень **приказа** (`tier: verified`) —
без участия человека. Это единственный способ заверить термин там, где
пользователь не владеет целевым языком, и единственное исключение из правила
«в медицине, фарме и юриспруденции приказ даёт только человек»: запрет
касается самоодобрения, а справочник находится вне контура системы.

Отсюда же следует главное требование: **сюда попадают только выверенные
источники**. Неверная строка здесь — не подсказка, которую модель вправе
проигнорировать, а приказ, который она обязана исполнить.

## Формат

Обычный TSV в UTF-8. Заголовок — в комментариях:

```
# label: ВОЗ INN — международные непатентованные наименования
# lang: RU→EN
# domains: medical, pharma
аторвастатин	atorvastatin
бисопролол	bisoprolol
```

| Поле | Обязательно | Смысл |
|---|---|---|
| `label` | нет | Как источник называется человеку. По умолчанию — имя файла |
| `lang` | **да** | Языковая пара. Файл без неё пропускается: применять его не к чему |
| `domains` | нет | Список областей через запятую или `*` для любой. По умолчанию `*` |

`domains: *` означает «любая предметная область» — так устроены IATE и UNTERM.
На языки это не распространяется никогда: пара обязательна всегда, и английский
справочник не подойдёт узбекскому переводу ни при каких условиях.

Один термин может иметь несколько переводов — просто повторите строку с тем же
оригиналом. Совпадением считается любой из них.

## Куда класть

- **`backend/authority_data/`** (этот каталог) — источники, которые едут в git
  вместе с кодом и общие для всех установок.
- **`backend/data/authorities/`** — то, что добавил владелец конкретного
  сервера. В git не хранится, как и всё в `data/`.

Оба каталога читаются при старте сервиса. Добавили файл — перезапустите
`medcat`, и в журнале появится строка с числом загруженных терминов.

## Откуда брать данные

Свободные источники, пригодные для загрузки:

| Источник | Области | Языки |
|---|---|---|
| **IATE** (терминологическая база ЕС) | любые | 25+ |
| **ICD-10 / ICD-11** (ВОЗ) | медицина | официальные переводы |
| **INN / ATC** (ВОЗ) | фарма | международные |
| **UNTERM** (ООН) | любые | 6 официальных языков |
| **IEC Electropedia** | техника | многоязычный |

Лицензии проверять до загрузки: UMLS требует аккаунта, MedDRA платная,
SNOMED доступна не во всех странах. Строить на свободных, платные подключать
ключом клиента.

## Чего здесь быть не должно

Машинного перевода, выгрузок из собственного глоссария и вообще всего, что
порождено этой же системой. Смысл справочника в том, что он **вне** контура:
источник, собранный из наших же переводов, подтверждает не термин, а нашу
собственную ошибку.
