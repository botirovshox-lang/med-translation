# Каталог: элементы документа, правила набора, форматы

Страница собрана `tools/catalog_report.py` из `backend/doc_catalog/*.json` — правьте
данные, а не её. Статус выводится: covered — есть наши правила и тест при них;
partial — правила есть, теста не названо; missing — в работе, правил нет.

## Форматы: что значит «тот же файл»

| Формат | Уровень | Что выходит | Потери |
|---|---|---|---|
| docx (.docx) | T1 | тот же .docx | номера страниц пересчитывает Word при открытии; выделения внутри абзаца — по границам, найденным в переводе, часть — приблизительно |
| pdf-text (.pdf) | T2 | PDF «как в оригинале» | прежний текст остаётся под закраской: «скопировать текст» отдаёт и его; повёрнутая страница (/Rotate) не трогается; номера страниц не переводятся |
| pdf-scan (.pdf) | T3 | PDF из перерисованных страниц | чтение надписей платное и может ошибаться; почерк автора не воспроизводится — ближайший рукописный шрифт |
| image (.png .jpg .jpeg .webp .tif .tiff .bmp .gif) | T3 | та же картинка тем же форматом | значок посреди строки не переносится; надпись по дуге длиннее дуги уходит плашкой |
| xlsx (.xlsx) | T1 | та же книга Excel | картинки, диаграммы, фигуры и примечания листов не сохраняются; перенос строки в ячейке становится пробелом |
| pptx (.pptx) | T1 | та же презентация | выделения внутри абзаца не сохраняются; заметки, диаграммы и SmartArt не переводятся; вылет текста за фигуру не проверяется |
| html (.html .htm) | T1 | та же страница | выделения внутри абзаца (жирный, ссылки) в переводе не сохраняются |
| text (.txt .md .markdown .log) | T1 | тот же текстовый файл | — |
| csv (.csv .tsv) | T1 | та же таблица | — |
| subtitles (.srt .vtt) | T1 | тот же файл субтитров | разметка внутри реплики (курсив, цвет) не сохраняется |
| video (.mp4 .mov .mkv .webm .avi) | T1 | видео с дорожкой субтитров, субтитрами в кадре или озвучкой | губы не синхронизируются, голос не клонируется |
| word-only (.json .xml .po .yaml .yml .rtf .odt .ods .odp .epub) | T4 | документ Word | построчная обратная запись сломала бы синтаксис — файл того же вида не выгружается |
