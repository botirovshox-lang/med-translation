# Перевод видео: сценарии и как система с ними обходится

Сводка на 27.09.2026. Конвейер: звук → распознавание (whisper-1, кусками по паузам)
→ строки-фразы → перевод → субтитры (файлом, дорожкой, в кадре) и/или озвучка
(синтез → подложка без голоса оригинала → сведение). Правила — инвариант 38 в
CLAUDE.md, план — BACKLOG.md («Голосовой контур»).

Обозначения: ✅ сделано · ⚠️ работает с оговоркой, названной на экране · ⏳ отложено (почему).

## 1. Речь и языки

| Сценарий | Что происходит | Статус |
|---|---|---|
| Один язык речи, чистая запись | распознаётся с подсказкой пунктуации языка (`asr_hints.json`), фразы → строки | ✅ |
| Язык перевода без родного голоса у синтеза (киргизский, таджикский, туркменский, латынь, панджаби, баскский) | маршрут отдаёт OpenAI «с акцентом», и это сказано ДО сборки | ⚠️ |
| Узбекский (латиница и кириллица) | у OpenAI его нет в списке языков синтеза → «робот»; родной голос — Azure uz-UZ (Madina, Sardor), кириллица переписывается в латиницу по таблице 1995 г. | ✅ при ключе Azure, иначе ⚠️ «с акцентом» |
| В ролике строки УЖЕ на языке перевода | распознавание идёт с языком оригинала: такую речь whisper сам переводит в язык оригинала, потом она переводится обратно и озвучивается поверх | ⏳ нужна галочка «в видео несколько языков» — распознавание с автоопределением, и тогда строки, где язык = язык перевода и ≥3 слов, остаются голосом оригинала. Правило «перевод = оригиналу» без автоопределения не срабатывает там, где нужно, и срабатывает на «OK» и именах |
| Третий язык в ролике | то же: whisper переводит его в язык оригинала, перевод модели справляется | ⚠️ смысл сохраняется, оригинальная фраза теряется |
| Смена языка внутри фразы (code-switching) | whisper выбирает один язык куска | ⚠️ |
| Диалект, акцент, жаргон | качество распознавания падает; строки правятся руками | ⚠️ |
| Числа, сокращения, единицы в озвучке | движок синтеза читает сам по правилам языка | ✅ |

## 2. Трудно выделить речь

| Сценарий | Что происходит | Статус |
|---|---|---|
| Тишина, музыка без речи | выдумки распознавания отсеиваются (`no_speech_prob`, `compression_ratio`) | ✅ |
| Громкая музыка/шум под речью | whisper слушает смесь, ошибается чаще | ⏳ «распознать заново с очисткой от музыки» — по стеме голосов (разделение уже есть); по кнопке, а не всегда: на чистой записи стема портит звук |
| Песни, вокал | распознаются как речь и переводятся/озвучиваются | ⚠️ надёжного признака «это песня» нет; строки песни человек удаляет. Подложка убирает пение только под клипами озвучки |
| Несколько говорящих, перебивают друг друга | одна строка — один голос озвучки | ⏳ диаризация (sherpa-onnx) и голос на говорящего |
| Тихая или далёкая речь | распознаётся хуже; озвучка — ровного уровня | ⏳ `loudnorm` дорожки озвучки (не подгонка по RMS — та качает шум) |
| Шёпот, крик, эмоции | голос озвучки ровный | ⏳ клонирование/эмоции — модели под GPU |

## 3. Фон и сведение

| Сценарий | Что происходит | Статус |
|---|---|---|
| Голос оригинала под озвучкой («две дорожки») | под клипом — фон без голоса (Spleeter), вне клипа — оригинал целиком; замер: −8 → −23 дБ | ✅ |
| Клип короче/длиннее реплики | маска — до позднего из концов клипа и реплики | ✅ |
| Смех, вздохи, звуки между репликами | остаются: вне маски оригинал | ✅ |
| Непереведённые строки | звучат голосом оригинала | ✅ |
| Разделение недоступно (нет модели/пакета, сбой, >120 мин озвучки) | прежнее приглушение, причина на экране, счёт в метриках | ⚠️ |
| mp3/ogg без индекса | звук один раз во FLAC, куски из него — без щелчков на стыках | ✅ |
| Звук начинается позже картинки (TS, .mov) | дополняется тишиной, фон не едет | ✅ |
| Перевод длиннее реплики | ускорение до 1,3 (1,5 — «быстро»), не влезло — номера строк | ⚠️ ⏳ укоротить перевод моделью |

## 4. Файл

| Сценарий | Что происходит | Статус |
|---|---|---|
| Файл без звука | распознавать нечего — строк нет, озвучивать нечего | ✅ отказ словами |
| Несколько звуковых дорожек (языки, комментарий) | берётся первая — одинаково для распознавания, разделения и сведения | ⏳ выбор дорожки по метке языка: один `audioIndex` на ВСЕ три шага сразу, иначе рассинхрон |
| Только звук (подкаст) | результат — .m4a | ✅ |
| До 2,5 ГБ, до 180 мин | загрузка кусками с докачкой; потолки | ✅ |
| Обрезка | распознаётся и собирается только отрезок, сдвиг на ключевой кадр учтён | ✅ |
| Надписи в кадре | не переводятся: кадры не декодируем | ⏳ |
