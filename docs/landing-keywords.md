# Семантическое ядро лендинга click.simpletranslate.me

Составлено 24.09.2026. **Частоты НЕ проверены**: Wordstat требует входа в аккаунт
Яндекса. Колонки «Wordstat» и «Решение» заполняет человек. Приоритет — моя
оценка по интенту и конкуренции, а не по данным.

## Как проверять в Wordstat

1. Регион — **Узбекистан** (и отдельно «Россия» для русских запросов:
   клиенты — русскоязычные авторы и там тоже).
2. Смотреть **точную частоту** в операторах `"!перевод !документов !онлайн"`,
   а не общую: общая включает «перевод документов для визы» и прочий шум.
3. Слева в выдаче Wordstat («что ещё искали») — источник новых фраз. Нашли
   хорошую — допишите в таблицу.
4. Запрос с точной частотой меньше **10 в месяц** в ядро не берём.
5. Запросы с «бюро», «нотариальный», «апостиль», «для визы», «присяжный»,
   «Минск», «Москва» — **минус-слова**: это нотариальный перевод людьми, его
   мы не продаём.

тестом по длине: title 30–60 знаков, description 120–160.

## Что делать после проверки

1. Фразы с «Решение: да» из кластеров А–В — в `META[...]["keywords"]`
   в `tools/landing_build.py`, затем `python tools/landing_build.py`.
2. Если кластер Б или Г даёт больше 100 точных показов в месяц — это повод
   для **отдельной страницы** («Перевод PDF с сохранением форматирования»,
   «Перевод научной статьи на английский»): одна страница хорошо ранжируется
   по одному интенту, а не по всем сразу.
3. Минус-слова из пункта 5 — в Яндекс Директ, когда дойдёт до рекламы.
